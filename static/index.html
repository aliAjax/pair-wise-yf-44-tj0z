常用接口

POST /api/loops                 登记仪表回路（量程、仪表版本）
POST /api/changes               建变更单；revise 动作登记回路定值
POST /api/tests                 登记功能试验（依据变更版本+仪表版本）
POST /api/batches               建投产批次；submit 动作逐项复算签认
GET  /api/batches/<id>          批次与每回路复算明细（问题码）
GET  /api/ledger?status=active  当前生效账
GET  /api/ledger/loops/<id>     回路详情：有效版本、来源、待复核、未完成项
GET  /api/reviews?status=pending 待复核
GET  /api/entities/<id>
POST /api/entities/<id>/actions
